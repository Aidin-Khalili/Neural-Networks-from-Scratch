# Neural Networks from Scratch

![Python](https://img.shields.io/badge/Python-3776AB?logo=python&logoColor=white) ![C++](https://img.shields.io/badge/C%2B%2B-00599C?logo=cplusplus&logoColor=white) ![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)

Classic neural network models implemented from scratch, without deep learning frameworks, to understand how they learn.

| Model | Description | Language |
|---|---|---|
| [Hebb](Hebb) | Hebbian learning rule, 2-D bipolar data | Python |
| [McCulloch-Pitts](McCulloch-Pitts) | McCulloch–Pitts neuron with 4 binary inputs | C++ |
| [Perceptron](Perceptron) | Single-layer perceptron on 2-D data | Python |
| [Adaline](Adaline) | Adaline with bipolar labels | Python |
| [MLP](MLP) | Multi-layer perceptron with backpropagation | Python |
| [Single-Neuron-Projects-MSc](Single-Neuron-Projects-MSc) | Perceptron / Adaline experiments from the M.Sc. Neural Computing course (2024) | Python, Jupyter |

For deeper models (CNNs, RNNs, GANs, Transformers) see [Neural-Computing-and-Deep-Learning-Course-Projects](https://github.com/Aidin-Khalili/Neural-Computing-and-Deep-Learning-Course-Projects).
